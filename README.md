## 📦 Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm

### Installation
```bash
npm install --legacy-peer-deps
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
